# Tiktokenizer

Online tokenizer playground supporting DeepSeek, Qwen, and GLM models.

Supported models:
- [deepseek-ai/DeepSeek-V4-Flash](https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash)
- [Qwen/Qwen3.6-35B-A3B](https://huggingface.co/Qwen/Qwen3.6-35B-A3B)
- [zai-org/GLM-4.7](https://huggingface.co/zai-org/GLM-4.7)

## Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fliangshuai%2Ftiktokenizer&env=HF_API_KEY&envDescription=HuggingFace%20API%20Key%20used%20to%20download%20tokenizer%20files%20during%20build&envLink=https%3A%2F%2Fhuggingface.co%2Fsettings%2Ftokens&project-name=tiktokenizer&repository-name=tiktokenizer)

> **Note:** Set `HF_API_KEY` to your [HuggingFace access token](https://huggingface.co/settings/tokens) in the Vercel environment variables during deployment.
